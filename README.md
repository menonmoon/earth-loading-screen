# Earth Loading Screen — PWA

A rotating Earth loading screen that installs like an app. Dark space
backdrop, orbiting satellites, a loading sequence that counts to 100%,
holds on "SYSTEMS ONLINE," then loops. Tap anywhere to restart it.

## Add it to your iPhone home screen

1. Open the live site in **Safari**.
2. Tap **Share** → **Add to Home Screen**.
3. It gets the Earth icon and opens fullscreen, no browser chrome —
   works offline too.

## Files

- `index.html` — the whole app (markup, styles, loading logic)
- `manifest.webmanifest` — PWA manifest
- `sw.js` — service worker (cache-first, offline support)
- `earth.jpg` — equirectangular Earth texture (NASA Blue Marble
  data via Solar System Scope, CC BY 4.0)
- `icon-*.png` — home-screen / PWA icons, generated by `make_icons.py`
